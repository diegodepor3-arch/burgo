# Product

## Platform

web

## Stack

HTML, CSS y JavaScript estáticos, sin frameworks (motor heredado de la web del Ural Español). `actualizar.py` genera `federacion.js` desde futgal.es (club 1045) cada hora con GitHub Actions; Vercel redespliega.

## Product Purpose

Web del Sporting Burgo (O Burgo, Culleredo, desde 1976): 14 equipos — Sénior A (2ª Futgal) y B, femenino sénior (2ª División) y F-7, juveniles, cadetes, infantiles, alevín, benjamín, prebenjamín y veteranos.

## Data

- futgal.es bloquea la IP tras unas decenas de páginas: cada ejecución sigue donde lo dejó la anterior.
- Equipos femeninos llevan id `-fem` (p. ej. `cadete-a-fem`).

## Brand

- Escudo: paraguas sobre un puente de arcos, franja azul de Galicia. Celeste #8fd0ec y marino #0e2a47 sobre fondo claro.
- Motivos: arcos del puente (borde de la portada, tarjetas de categorías) y la franja diagonal.
- Tipografía: Archivo (ancha en títulos).
- Distinta de Montañeros/Rayo (oscuras), Ural (verde y oro) y Santa Cruz (azulgrana).
